# Diedro

App Android gratuita y **100 % offline** que genera planos de fabricación (vistas, cotas, tolerancias, hojas de pieza y de conjunto) a partir de archivos STEP. Sin anuncios, sin cuentas, sin permiso de Internet.

- Privacidad: `PRIVACY.md`.
- Compilación: `BUILD.md`.

Estructura: `core/` (núcleo C++ con OpenCASCADE), `android/` (interfaz Java + JNI), `visor/app/` (visor 3D Flutter embebido), `i18n/` (21 idiomas).
